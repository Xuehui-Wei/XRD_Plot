# Fancy Plots for PeakPo

This repository provides an updated plotting function for grouped and ROI-highlighted JCPDS patterns in **PeakPo**.

## 📂 Contents
- `src/fancy_plots_update.py` – Updated plotting function with grouped phase and ROI bolding support.  
- `examples/example.ipynb` – Example Jupyter notebook demonstrating the new plotting features.  
- 📖 [Full Function Manual (Wiki)](https://github.com/Xuehui-Wei/XRD_Plot/wiki/manual)
